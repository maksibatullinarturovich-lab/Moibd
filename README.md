# Проекты по машинному обучению и анализу данных (МОИБД)

В данном репозитории собраны учебные проекты:

1. **movie_recommender** — Рекомендательная система фильмов:
   - REST API на FastAPI (Топ-10 популярных, User-Based CF, Item-Based CF, Content-Based TF-IDF, персональный гибрид SVD);
   - Интерактивное веб-приложение на Streamlit;
   - База данных MySQL с сохранением оценок пользователей;
   - ML-аналитика и диагностика моделей (RMSE, MAE, Precision, Recall, PCA 2D, Heatmap).

2. **moibd_estate** — Исследование и прогнозирование стоимости недвижимости.
